# Проект по автоматизации тестирования (Урок 10)

Данный проект содержит автоматизированные тесты для двух сценариев:
1. **Медленный калькулятор** — проверка работы с большими ожиданиями.
2. **Магазин SauceDemo** — проверка полного цикла покупки товаров.

## Структура проекта
- `pages/` (или корень) — классы Page Object с описанием страниц.
- `test_*.py` — файлы с тестами Pytest.
- `pytest.ini` — конфигурация запуска.
- `.gitignore` — исключение папок отчетов из репозитория.

## Подготовка к запуску
1. Установите необходимые библиотеки:
   ```bash
   pip install pytest selenium allure-pytest webdriver-manager flake8
   ```
2. Убедитесь, что у вас установлен браузер **Google Chrome**.

## Запуск тестов и формирование отчета
Для запуска всех тестов и генерации данных для Allure выполните команду:
```bash
pytest --alluredir=allure-results
```
*Папка `allure-results` будет создана автоматически. В репозиторий она не попадает благодаря `.gitignore`.*

## Просмотр отчета
Чтобы сгенерировать красивый HTML-отчет и открыть его в браузере, используйте команду:
```bash
allure serve allure-results
```

## Проверка стиля (PEP8)
Для проверки соответствия кода стандартам оформления выполните:
```bash
flake8 .
```
